# FamilieTools

FamilieTools is a modular family management platform designed to combine multiple family-related tools in one application.

## Goals

The project will be developed incrementally with a strong focus on:

- maintainable architecture
- security
- accessibility
- automated testing
- automated code quality checks
- self-hosted tooling where practical
- AI-assisted development with efficient context usage

## Development

The development environment and project architecture are currently being built from scratch.

## Status

Early development.
